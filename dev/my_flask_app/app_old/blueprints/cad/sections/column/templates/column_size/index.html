角形鋼管線記号変形テキスト制作アプリ

説明

このアプリは、角形鋼管のサイズに基づいて座標計算を行い、角形鋼管の断面を作図する線記号変形のテキストを作成します。

ユーザーは角形鋼管のサイズやその他のパラメータを指定し、角形鋼管の断面を作図する線記号変形のテキストを作成を実行します。

各値設定プルダウンの詳細説明を以下に示します:

  • 角形鋼管のサイズ: 角形鋼管のサイズを選択してください。
  • s1とs2: JW-CADの線記号変形の仕様に準拠した制御コードの値を入力します。s1=制御コード1。s2=制御コード2。
  • 基準点: 作図の基準点を指定します。1=左上 2=上 3=右上 4=左 5=中 6=右 7=左下 8=下 9=右下
  • 線色: JW-CADの線色設定に基づいた線色の値を指定します。(1～6)
  • 線種: JW-CADの線種設定に基づいた種類の値を指定します。(1～9)
  • レイヤー: JW-CADのレイヤー設定に基づいて作図するレイヤーの値を指定します。(0～9,A～F)
  • 部材数: ファイル内に追加できる線記号変形の最大数を指定します。設定数以上を追加してもそれ以降はリストに表示されません。(1～30)

使用方法

適切なオプションを選択し、「計算」ボタンをクリックして、結果を得てください。
