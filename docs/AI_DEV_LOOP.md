# AI Development Loop

This project uses an AI-driven development workflow.

The development loop consists of the following steps.

1. ChatGPT designs architecture and tasks.

2. Tasks are stored in:
   ai/prompts/codex_tasks/

3. Codex generates code based on tasks.

4. The application is tested locally.

5. Development history is recorded in:
   ai/context/PROJECT_MEMORY.md

6. Next tasks are designed.

This loop repeats during development.
